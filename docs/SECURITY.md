# 安全说明

## 提交前检查

- 不提交 `.env`、证书、私钥或支付配置。
- 不提交 `server/data/store.json` 或备份文件。
- 不提交 `server/public/uploads/` 中的运行时文件。
- 不提交 `project.private.config.json`。
- 使用真实数据测试后，重新执行凭据和个人信息扫描。

## 部署建议

- 为管理员、客服和工作台设置不同的强密码或口令。
- 使用 HTTPS 反向代理，不直接暴露 Node.js 端口。
- 将支付私钥放在服务目录之外，并限制文件权限。
- 定期备份业务数据，并对备份文件加密。
- 生产环境应将账号密码升级为带盐哈希存储。
- 支付、登录和消息回调凭据发生泄露时立即轮换。
